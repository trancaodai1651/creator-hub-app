# Voice co san

Dat cac tep prompt OmniVoice co dinh dang `.pt` vao thu muc nay.

- Ten tep se duoc dung lam ten hien thi trong bo chon giong doc.
- Cac tep `.pt` nay la prompt da tao tu quy trinh clone voice, khong phai tep am thanh `.wav`.
- Mo lai tab Giọng đọc AI hoac bam `Nap lai` de doc danh sach voice moi.
- Cac tep trong thu muc nay se duoc dong goi cung ban cai dat Tauri ke tiep.

Khong dat khoa API hoac thong tin rieng tu vao thu muc nay.
